# VIP Limit Index & Syndicate Allocation (VIP Liquidity Syndicate)

> **Концепция:** Закрытый клуб аудита лимитов и аллокации синдикатного капитала (VIP Liquidity Syndicate / Prop-Trading для VIP-игроков).
> Упаковка для китов с отрицательным балансом в крипто-букмекерах (Stake, Sportsbet.io, BC.Game, Roobet, Cloudbet), снимающая подозрения в скаме и мошенничестве.

## 🚀 Быстрый запуск

### Вариант 1: Запуск в браузере напрямую (Zero setup)
Просто откройте файл `index.html` (кинематографичная история) или `portal.html` (полный терминал) в любом браузере (Chrome, Safari, Brave). Все скрипты, шрифты и стили загружаются через CDN, калькулятор и формы работают автономно.

### Вариант 2: Запуск с локальным сервером и отправкой в Telegram

1. Скопируйте `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
2. Укажите ваш `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` (закрытая группа команды).
3. Запустите сервер:
   ```bash
   node server.js
   ```
4. Откройте `http://localhost:3000`.

## 💎 Реализованные экраны и функции

1. **Top Status Bar:**
   - Институциональный статус деска (`LIVE ALLOCATIONS: $1,840,000`, `ACTIVE POOLS: 42`, `AVG SPLIT: $2,840 USDT`).
2. **Экран 1: Hero Block:**
   - Сдержанный Bloomberg-стиль финтех без азартного мусора.
   - Бейджи доверия: *Non-Custodial (0 паролей)*, *0% личного риска*, *Выплаты в USDT*.
3. **Экран 2: Live Proof Ticker:**
   - Анимированная бегущая строка с реальными сценариями сессий (Stake Plat IV, Sportsbet Clubhouse, BC.Game SVIP).
4. **Экран 3: Интерактивный калькулятор дивидендов и рисков (Dividend & Risk Calculator):**
   - **Входы:**
     - VIP-Букмекер (Stake, Sportsbet.io, BC.Game, Roobet) с индивидуальными мультипликаторами ликвидности.
     - Неоновый светящийся слайдер подтвержденного лимита ($10,000 — $100,000) с динамическим градиентным треком и пресетами ($10k, $25k, $50k, $75k, $100k).
     - Количество сессий в месяц (интерактивный степпер +/- и слайдер 2–24 сессии с пресетами 4, 8, 12, 16 сессий).
   - **Живые выходы (Live Outputs с 60fps анимацией счетчиков):**
     - Выделяемый банкролл синдиката (Syndicate Bankroll Allocated, масштабируется от лимита).
     - Ожидаемый чистый профит за сессию (Expected Net Profit per Session, математический перевес EV edge ~12%).
     - Чистый дивиденд кита (Whale Dividend 30% Split in USDT, с отображением помесячного дохода и за 1 сессию).
     - Персональный риск для кита: **$0.00 (Zero Downside Risk)** с гарантией покрытия любых просадок резервным фондом деска.
   - Кнопка **«Забронировать слот аллокации»** с передачей всех параметров в модальное окно квалификации.
   - Модульный автономный движок: [`dividend-calculator.js`](dividend-calculator.js) и отдельная демо-страница [`calculator-demo.html`](calculator-demo.html).
5. **Экран 4: Индекс Лимитов / Leaderboard (Ego-Bait):**
   - Таблица подтвержденных рекордов ставок недели.
   - Ежемесячный призовой грант $3,000 за топ-3 лимита.
   - Анти-Inspect Element предупреждение.
6. **Экран 5: Почему это выгодно обеим сторонам:**
   - Сравнительная таблица «Обычный игрок (в тильте)» vs «VIP-партнер синдиката».
7. **Экран 6: Протокол безопасности (Non-Custodial & Secure Enclave):**
   - 4 столпа: 0 паролей, нулевой баланс на старте, аппаратная изоляция (Secure Enclave / No AnyDesk), мгновенный вывод на некастодиальный кошелек игрока (Ledger/Trust Wallet/SafePal).
8. **Экран 7: 4 шага подключения:**
   - Понятная дорожная карта от скриншота купона до поступления USDT.
9. **Экран 8: Экспресс-форма Lite-квалификации:**
   - 3 клика: БК + ранг/минус + Telegram @username + drag-and-drop купона.
   - Моментальная валидация и отправка в деск.
10. **Экран 9: Институциональный футер и юридический дисклеймер.**
11. **Процедурный Web Audio API движок (sound-engine.js):**
    - 100% чистый JavaScript без внешних файлов и аудио-библиотек (работает автономно и офлайн).
    - Кинематографичный low-volume лаунж-дроун (55Hz суб-бас + 5-я гармоника + дышащий LFO-фильтр 0.075Hz + шум пленочного пола).
    - Люксовый переключатель в хедере `[AUDIO: ON/OFF]` (клавиша `M`) с анимированным 3-полосным эквалайзером.
    - Тактильный хаптик-клик (Leica/Apple Taptic) на слайдере лимитов с частотной микромодуляцией.
    - Механический переключатель (CNC-relay) при смене БК, VIP-рангов и переходов между экранами.
    - Тяжелый саб-бас панч (38Hz drop) + кристальный металлический колокольный перезвон (D6/A6/D7/G7/C8) при согласовании выплаты и отправке заявки.
12. **VIP Concierge Application & Audit Modal (`vip-concierge-modal.js` & `vip-concierge-modal.html`):**
    - **4-шаговая институциональная квалификация:**
      1. *Выбор букмекера и VIP-ранга:* Stake (Plat I-Diamond/Obsidian), Sportsbet (Clubhouse Hero/Legend/Master), BC.Game (SVIP), Roobet, Cloudbet.
      2. *Аудит потолка ставки (1X2 на АПЛ/ЛЧ):* пошаговый регламент ввода $50k в купон топ-матча, фиксация `Max Bet` и Anti-Inspect Element протокол защиты от F12.
      3. *Формат сессии и локация:* VIP Lounge Dubai (DIFC), VIP Lounge Москва (Москва-Сити), Аппаратная защищенная сессия (Hardware Enclave Clean-Room) или изолированный сессионный профиль.
      4. *Реквизиты и выплата:* Telegram (@username) для связи со старшим консьержем, некастодиальный USDT кошелек (TRC20/ERC20) для дивидендов и выбор размера пула ($10k-$100k+).
    - **Двойной канал диспетчеризации:**
      - *Прямой Telegram Deep Link:* `https://t.me/<desk>?text=...` с автогенерацией форматированного тикета.
      - *Защищенный Webhook:* POST `/api/audit-request` в Node.js сервер с отправкой в Telegram Bot API.
    - **Автономный демо-стенд:** `vip-concierge-modal.html` для изолированного тестирования всех 4 шагов и генератора ссылок.
